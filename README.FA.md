# ابزار مدیریت NCSI و پروبینگ شبکه ویندوز

یک جعبه‌ابزار سبک و کاربردی برای ویندوز شامل فایل‌های رجیستری و بچ‌اسکریپت خودکار جهت مدیریت قابلیت **Active Probing** در سرویس تشخیص وضعیت اتصال شبکه (**NCSI**) و راه‌اندازی مجدد سریع سرویس `NlaSvc`.

این ابزار برای حل مشکل آزاردهنده «نمایش آیکون کره زمین یا علامت تعجب زرد و پیام No Internet Access با وجود وصل بودن اینترنت»، جلوگیری از باز شدن خودکار مرورگر (صفحات لاگین یا Captive Portal) و کنترل پایش‌های تلمتری مایکروسافت طراحی شده است.

---

## 📁 فایل‌های موجود در پروژه

| نام فایل | فرمت | عملکرد |
| :--- | :--- | :--- |
| **`Restart Network Service.bat`** | بچ‌اسکریپت | ارتقای خودکار به دسترسی ادمین و ری‌استارت سریع سرویس `NlaSvc` جهت اعمال فوری تنظیمات. |
| **`Enable Internet Probing.reg`** | فایل رجیستری | مقداردهی `EnableActiveProbing = 1` برای بازگرداندن سیستم بررسی پیش‌فرض ویندوز. |
| **`Disable Internet Probing.reg`** | فایل رجیستری | مقداردهی `EnableActiveProbing = 0` برای توقف پایش مداوم و ارسال درخواست به سرورهای مایکروسافت. |

---

## ✨ قابلیت‌ها و ویژگی‌ها

* 🔑 **ارتقای خودکار دسترسی ادمین:** اسکریپت سطح دسترسی را بررسی کرده و در صورت نیاز پیام تأیید UAC را از طریق پاورشل به صورت خودکار باز می‌کند.
* ⚡ **اعمال تغییرات بدون ری‌استارت سیستم:** ری‌استارت تمیز سرویس `NlaSvc` به همراه سرویس‌های وابسته (`/y`) که وضعیت آیکون شبکه را ظرف چند ثانیه بدون خاموش و روشن کردن کامپیوتر به‌روزرسانی می‌کند.
* 🌐 **حل خطای کاذب قطع اینترنت:** رفع مشکل عدم نمایش وضعیت واقعی اتصال در تسک‌بار هنگامی که سایت‌ها باز می‌شوند اما ویندوز وضعیت را بدون اینترنت نشان می‌دهد.
* 🛡️ **کنترل تلمتری و حریم خصوصی:** جلوگیری از ارسال مداوم پینگ و درخواست‌های HTTP پس‌زمینه به آدرس‌های مایکروسافت (`msftconnecttest.com`).
* 📦 **کاملاً بومی:** بدون نیاز به نصب هیچ ابزار خارجی؛ متکی به تنظیمات پیش‌فرض ویندوز.

## 🚀 راهنمای استفاده

### مرحله ۱: انتخاب وضعیت مورد نظر
* برای **غیرفعال‌سازی** پایش اینترنت (حل خطای کاذب یا قطع درخواست‌های اضافه):  
  روی فایل **`Disable Internet Probing.reg`** دو بار کلیک کرده و پیام تأیید را Yes بزنید.
* برای **فعال‌سازی مجدد** به حالت پیش‌فرض ویندوز:  
  روی فایل **`Enable Internet Probing.reg`** دو بار کلیک کرده و پیام تأیید را Yes بزنید.

### مرحله ۲: اعمال فوری تنظیمات
* روی فایل **`Restart Network Service.bat`** دو بار کلیک کنید.
* در صورت نمایش پنجره دسترسی **UAC**، گزینه **Yes** را انتخاب کنید.
* سرویس شبکه متوقف و مجدداً اجرا می‌شود و آیکون شبکه در تسک‌بار پس از ۵ ثانیه رفرش خواهد شد.
